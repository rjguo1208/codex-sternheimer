# Sternheimer Electron-Defect HTML Report

This repository publishes a static GitHub Pages report generated from an HPC
working directory for active/rest electron-defect T-matrix calculations.

The public website artifact is in `docs/`:

- `docs/index.html`
- `docs/assets/*.png`

Large raw calculation outputs, wavefunctions, binary tensors, cube grids,
scheduler logs, and local configuration files are intentionally excluded by
`.gitignore`.
